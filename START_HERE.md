# Start here
Extract the sanain folder into a new working directory. Install Git, GitHub CLI, Rust via rustup and Claude Code using official instructions. Open a terminal in the folder, run `claude`, and paste BOOTSTRAP.md. Claude inspects the environment and starts M0. No application or remote repository exists in this package. Authenticate interactively when needed; never paste secrets into prompts. Approve the initial decision packet and automation policy; routine work thereafter is delegated within those limits. See docs/OWNER_GUIDE.md and docs/AUTONOMY.md. Unattended work requires an approved runner; the session alone is not a background service.
