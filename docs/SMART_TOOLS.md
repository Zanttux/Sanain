# Smart Views and Smart Actions
Views are opt-in via toolbar or palette; extension/content detection suggests but never forces a view. Plain source always available. JSON tree, CSV grid, XML/YAML inspection, Markdown preview, log viewer. Edits in a structured view must map to explicit source transactions; if fidelity cannot be guaranteed, ship read-only view first. Preserve duplicate JSON keys and number lexemes or warn before transformation. CSV delimiter/quote/newline detection is user-overridable. XML disables external entities and DTD resolution; YAML limits aliases/depth and never executes tags.

Action registry: id, label, applicable MIME/selection, input limits, pure transform, preview, error, undo transaction. Initial actions: JSON format/minify/validate, URL encode/decode, Base64, UUID, timestamp conversion with explicit timezone, sort/dedupe lines, case conversion, trim whitespace, newline conversion. Never execute SQL, shell or URLs automatically. Detect locally, show suggestions only; no network. Batch changes show diff and require confirmation. Diff supports two tabs/files/clipboard, whitespace options, line and intraline highlighting, selected hunk apply with revision check. Test malformed input, huge selections, cancellation and undo.

## Reusable pipelines
Compose deterministic offline transformations as declarative, versioned steps with preview, cancellation, bounded resources and one undoable transaction. Import/export recipes as data, never executable scripts. Validate schemas and reject unknown steps. Example: Base64 decode → parse JSON → sort keys → format → replace selection.
