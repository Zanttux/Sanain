# Brand system — proposed v0.1
Display name Sanain; technical slug sanain; pronunciation approximately “SAH-nine”. Positioning: a native, free, open-source editor for everyday text and technical files. Tagline: **The power of words.** Secondary: AI-built. Human-led. Community-driven. Open source promise: Free. Forever. For everyone. Never imply official Notepad++ affiliation. Avoid unverified claims of speed, accessibility or AI provenance.

## Principles
Sanain should look like an established desktop tool built for daily work.
- Every element has a job. No decorative gradients, glows, sparkles or
  purple-blue "AI" palettes.
- The wordmark is set in one colour. It does not highlight "ai"; AI's role
  is disclosed in the README and policy, not encoded in the logo.
- System UI font for the interface, system monospace for text, until a
  specific typeface is justified by legibility testing.
- Follow platform conventions for menus, shortcuts, dialogs and focus.
- Design for long sessions: calm contrast, no motion without purpose.

## Visual identity
A dark rounded square with a clean mint S mark; no mascot or borrowed marks. Use assets/brand/icon.svg and wordmark.svg as editable concept masters. Keep clear space of 1/4 icon width; minimum icon 16 px (test simplified mark at 16); no gradients, shadows or stretching. Export platform icons (ICO, ICNS, PNG, Linux SVG) after name approval. Font: system UI for application; system monospace for editor, configurable. Wordmark uses generic sans-serif; convert to paths only after selecting a redistributable font.

Accent is not the only status cue. Validate WCAG 2.2 AA contrast for actual foreground/background pairs, focus, selection, syntax tokens and disabled states. Respect system light/dark/high contrast and reduced motion. Never force brand colors into syntax themes. Use 4px spacing grid, 8px controls, visible keyboard focus, scalable text and native conventions. Marketing screenshots must be real builds, not fabricated UI. Brand files are concepts, not cleared trademarks. Owner approves final mark and brand asset licensing before publication.
