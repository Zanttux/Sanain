# Distribution
Windows x64/ARM64, macOS Apple Silicon/Intel, Linux x64 initially candidates; advertise only tested targets. Windows installer and portable; macOS signed/notarized bundle; Linux archive/AppImage or distro packages after validation. Verify signing costs, store requirements and licenses. CI builds from tagged commit with lockfile, generates checksums and SBOM, attaches notices and release notes. Human approves publishing. No auto-updater until signed manifest, rollback and threat model exist. CLI proposed: sanain path, sanain --diff a b, sanain --new; --tail later. No shell interpolation of file paths. Migration: import supported Notepad++ settings/keymaps only with consent; never modify originals.
