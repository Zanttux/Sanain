# Owner guide
You are Founder & Project Lead. Claude handles routine engineering, planning, GitHub, community, documentation and release preparation. You set direction, budget and reserved decisions. A repository is files plus history; an issue is a task; a branch is a working copy; a PR proposes changes; CI checks them; a merge accepts them. You need not manage these manually.

Install tools, start Claude and paste BOOTSTRAP. Authenticate GitHub interactively with 2FA/passkeys; never share passwords or tokens. Approve the consolidated initial decision packet and scoped automation policy. Once activated, Claude handles routine tasks without asking each time. Review concise summaries and intervene when desired. External PRs and stable releases initially require approval; see AUTONOMY for policy evolution. No fake reviews. Keep recovery access, spending limits and a kill switch. Unattended operation requires a separately configured runner. If compromised, stop runner, revoke credentials, preserve logs and review changes before resuming.
