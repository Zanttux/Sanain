# Markdown specification
P0: CommonMark + GFM tables, task lists, strikethrough, autolinks, fenced code, images, heading anchors, YAML front matter display, outline and generated TOC on explicit command. Source, split and read-only preview; remember per-document mode. Source always editable and authoritative; no auto-reformat on open. Scroll sync via AST source ranges, not percentage alone. Code highlighting and offline Mermaid (evaluate compatible renderer; do not use remote CDN). Unsupported diagrams show source and clear error. P1: math, PDF/HTML export, link checker, image paste, visual table editing. P2: rich editing only after round-trip fidelity proven.

Security: sanitize HTML or disable raw HTML by default; no scripts, remote images or network fetch by default. Explicit external link confirmation where needed; block javascript/file traversal and unsafe schemes; resolve relative images against document directory with user permission for outside paths. Bound image size, AST depth and rendering time. Mermaid rendering must be isolated, offline and non-executable from document content. Test malformed markdown, Unicode, nested lists, duplicate headings, huge tables, malicious HTML, scroll sync and unchanged source bytes. Do not silently change task list syntax or front matter.
