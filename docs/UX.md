# UX specification
Default window: menu, optional compact toolbar, tabs, editor, status bar (line/column, selection, encoding, newline, syntax). Sidebar hidden by default. Command palette fuzzy search (Cmd/Ctrl+Shift+P) and Goto Anything (Cmd/Ctrl+P: files, `:line`, `@symbol`, `#text`); discoverable menu equivalents. Windows familiar shortcuts Ctrl+N/O/S/F/H, macOS native Cmd equivalents; configurable conflicts. Keyboard-only operation, visible focus, accessible labels, high contrast, scaling 100–200%, screen reader and IME testing. No modal on startup, no sponsorship nag, no forced project. First run opens scratch buffer; restore previous session by default with opt-out. Quitting keeps unsaved and untitled tabs for the next start without prompts (hot exit, on by default, opt-out in Settings); closing a single tab still asks. Several running instances keep their own unsaved tabs; the last one to quit sets the tab order for the next start, and the others' tabs follow. Sponsor link in About and website only. Error messages explain cause, preservation of edits and recovery path. Avoid mimicking Notepad++ branding or icons. Design tokens for spacing, typography, semantic colors; verify contrast. No claims of accessibility until tested.
