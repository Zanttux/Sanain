Philosophy

Text³ is a file editor, not a project tool. You open a file and edit it. The Markdown preview and the views for structured data sit beside the text, and you can close them at any time.

The window holds tabs, the editor, a menu and a status bar. Other panels appear only when you open them, and the editor has no built-in AI features.

Large changes are shown before they happen: Replace All has a preview, and Replace in Files keeps the previous version of each file in local history.

Your work stays on your computer. Text³ works offline and needs no account; the Privacy section below has the details.

Every feature is free for everyone. The code is open source under the Mozilla Public License 2.0 and developed in public on GitHub, where the plans and decisions behind it can be read.

What it does

Editing

Tabs and a split view, multiple cursors, macros and folding. Keyboard shortcuts can be changed, and a Notepad++ preset is included.

Find and replace

Search with regular expressions in one file or across a folder, with a preview before Replace All.

Markdown

Source and preview side by side, with tables, task lists, local images and an outline. Nothing in a document runs or loads from the network.

Data and logs

Tree views and validation for structured formats such as JSON and YAML, a CSV grid, side-by-side comparison, and a log viewer that opens files of any size.

Languages

Highlighting for 22 languages, including languages inside others, such as JavaScript in HTML or code blocks in Markdown. The interface is in 26 languages.

Comfort

Light, dark, high-contrast and bundled terminal themes and your own font. Sessions are restored, and a portable mode runs from a USB stick.

Privacy

Text³ works offline by default and collects no telemetry. There are no accounts or ads. File contents never leave your computer. The only network use is an update check you can turn on, which asks GitHub whether a newer version exists.

About the project

Text³ is written by Claude, an AI model by Anthropic, working as the developer under the direction of the project's founder, who decides what it becomes. Every change goes through automated tests on each supported operating system before it is merged, and the work is public on GitHub.
