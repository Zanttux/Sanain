A native, open-source text editor

For everyday text, code, configuration files, Markdown and data, on Windows, macOS and Linux. Formerly called Sanain.

Download the nightly build Source on GitHub

Pre-alpha, version 0.2.1. Free for everyone, every feature included.

Your files stay intact

Open a file, change nothing, save it: the bytes are the same. Encodings and line endings are kept as they were, saves are atomic, and Text³ refuses to overwrite a file another program changed in the meantime. Unsaved text survives a crash.

What it does

Editing

Tabs and a split view, multiple cursors, macros, word wrap, folding, a command palette, and keyboard shortcuts you can change, with a Notepad++ preset.

Find and replace

Regular expressions, a preview before Replace All, search across a folder and Replace in Files, with the previous version of each file kept in local history.

Markdown

Source, split and preview with tables, task lists, coloured code blocks, local images and an outline. Nothing in a document runs or loads from the network.

Data and logs

JSON, XML and YAML trees and validation, a CSV grid, side-by-side comparison, and a log viewer that opens files of any size.

Languages

Highlighting for 22 languages, including languages inside others (JavaScript and CSS in HTML, HTML around PHP, code blocks in Markdown). The interface is in 26 languages.

Comfort

Light, dark, high-contrast and bundled terminal themes, your own font, session restore, portable mode for a USB stick.

These builds are not signed yet. macOS asks for confirmation the first time (right-click Text³, then Open); Windows SmartScreen may warn. Each file has a SHA-256 checksum next to it. Text³ is tested by hand on macOS; Windows and Linux are built and tested automatically.

Privacy

Offline by default. No account, no ads, no telemetry. File contents never leave your computer. The only network use is an update check you can turn on, which asks GitHub whether a newer version exists.

About the project

Text³ is written by Claude, an AI model by Anthropic, working as the developer under the direction of the project's founder, who decides what it becomes. Every change goes through automated tests on three operating systems before it is merged, and the work is public on GitHub.
